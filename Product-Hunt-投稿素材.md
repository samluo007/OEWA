### 3. 产品描述（Short description，300字符内）
OEWA is an enterprise AI Agent workflow automation platform built specifically for recruiters and RPO companies. It automates JD parsing, candidate matching, outreach emails, and interview scheduling — all without writing a single line of code.

### 4. 详细描述（Full description）
**The problem:** Most AI Agent platforms (CrewAI, LangChain, LangFlow) are built for developers. But recruiting and RPO professionals don't write code — they need to automate hiring workflows immediately.

**The solution:** OEWA (OpenClaw Enterprise Workflow Automation) is the first AI Agent workflow platform built specifically for recruiting and RPO. Pick a YAML template, fill in your inputs, run the workflow — that's it.

**Key features:**
- Drop in a job description → automatically parse requirements
- Match candidates → generate personalized outreach emails
- Schedule interviews → auto-send calendar invites
- Industry templates: Recruiting, E-commerce CS, Marketing Automation, Data Reports
- Zero code — YAML-config based, open source

**Why it matters:**
Recruiters spend 60%+ of their time on repetitive tasks (JD parsing, resume screening, outreach drafting). OEWA automates those workflows so recruiters can focus on what matters — finding the right person, faster.
