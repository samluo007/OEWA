# OEWA 用户指南 v1.0

## 🎯 简介
OEWA（OpenClaw Enterprise Workflow Automation）是一站式企业AI Agent工作流自动化平台，让企业业务流程自动化像搭积木一样简单。

## 🚀 快速开始

### 1. 访问系统
```
前端地址：http://localhost:3000
后端API：http://localhost:8000
API文档：http://localhost:8000/docs
```

### 2. 创建第一个工作流

**步骤1：点击"新建工作流"**
- 点击右上角的"新建工作流"按钮
- 输入工作流名称（必填）
- 输入描述（可选）
- 选择行业（电商/营销/客服）

**步骤2：在画布上编排工作流**
- 从左侧节点面板拖拽节点到画布
- 连接节点（点击节点边缘的圆点，拖动到目标节点）
- 配置节点参数（双击节点打开配置面板）

**步骤3：保存并执行**
- 点击"保存"按钮保存工作流
- 点击"执行"按钮运行工作流
- 查看执行结果和监控面板

### 3. 使用行业模板

**步骤1：打开模板库**
- 点击左侧边栏的"模板库"按钮
- 查看已发布的行业模板

**步骤2：选择模板**
- 选择需要的行业模板（电商客服/营销自动化/数据报告）
- 点击"使用模板"按钮

**步骤3：一键创建**
- 模板将自动创建工作流
- 根据实际需求调整节点配置
- 保存并执行

## 🎨 节点类型

### LLM节点
- **用途：** 调用AI语言模型（GPT-4o、Claude等）
- **参数：**
  - 模型选择（gpt-4o / claude-3-opus）
  - 系统提示词
  - 用户输入
- **输出：** AI生成的文本响应

### API节点
- **用途：** 调用第三方HTTP API
- **参数：**
  - 请求方法（GET/POST/PUT/DELETE）
  - URL地址
  - 请求头
  - 请求体
- **输出：** API响应内容

### 条件节点
- **用途：** 根据条件分支执行不同路径
- **参数：**
  - 条件表达式（如：`input.age > 18`）
  - True分支（满足条件时执行）
  - False分支（不满足条件时执行）

### 循环节点
- **用途：** 循环执行一组节点
- **参数：**
  - 循环次数（固定次数）
  - 循环条件（满足条件时继续）
  - 循环体（要重复执行的节点）

### 数据库节点（Phase 2）
- **用途：** 执行数据库查询和写入
- **参数：**
  - 数据库连接
  - SQL语句
  - 参数绑定

### 消息队列节点（Phase 2）
- **用途：** 发送和接收消息
- **参数：**
  - 队列名称
  - 消息内容
  - 超时时间

## 🔧 最佳实践

### 工作流设计
1. **保持简单：** 每个工作流不要超过20个节点
2. **错误处理：** 在关键节点添加错误处理逻辑
3. **日志记录：** 使用日志节点记录重要信息
4. **模块化：** 将重复使用的逻辑封装为子工作流

### 性能优化
1. **异步执行：** 不依赖结果的节点并行执行
2. **缓存结果：** 重复调用的API启用缓存
3. **限流控制：** 避免同时执行过多工作流

### 安全建议
1. **API密钥：** 不要在前端代码中硬编码API密钥
2. **权限控制：** 使用RBAC模型管理用户权限
3. **数据加密：** 敏感数据使用HTTPS传输

## 📊 监控与调试

### 查看执行记录
1. 打开"监控面板"
2. 查看历史执行列表
3. 点击某条记录查看详细执行结果

### 调试工作流
1. 使用"模拟执行"模式（不调用真实API）
2. 查看每个节点的输入输出
3. 使用断点功能暂停执行

### 性能监控
1. 查看"平均执行时间"指标
2. 监控"成功率"指标
3. 设置告警阈值

## 📋 常见问题

### Q1：工作流执行失败怎么办？
**A：** 
1. 查看执行记录中的错误信息
2. 检查节点配置是否正确
3. 检查网络连接是否正常
4. 查看后端日志（`/var/log/oewa/`）

### Q2：如何导入已有工作流？
**A：** 
1. 点击"导入"按钮
2. 选择YAML文件
3. 验证工作流配置
4. 保存到工作流列表

### Q3：如何导出工作流？
**A：** 
1. 选择要导出的工作流
2. 点击"导出"按钮
3. 选择导出格式（YAML/JSON）
4. 下载文件到本地

### Q4：如何添加自定义节点类型？
**A：** 
1. 在`src/nodes/`目录创建新的节点组件
2. 在`nodeTypes.js`注册节点类型
3. 在后端实现节点执行逻辑
4. 更新API文档
