## 二、数据库模型设计（PostgreSQL）

### 2.1 工作流表 (workflows)
```sql
CREATE TABLE workflows (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(255) NOT NULL,
    description TEXT,
    industry VARCHAR(50),  -- 'ecommerce', 'marketing', 'customer_service'
    yaml_config TEXT NOT NULL,  -- 工作流YAML定义
    status VARCHAR(20) DEFAULT 'draft',  -- draft, active, archived
    created_by UUID,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_workflows_status ON workflows(status);
CREATE INDEX idx_workflows_industry ON workflows(industry);
```

### 2.2 执行记录表 (executions)
```sql
CREATE TABLE executions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    workflow_id UUID REFERENCES workflows(id),
    status VARCHAR(20),  -- pending, running, success, failed
    input_data JSONB,
    output_data JSONB,
    error_message TEXT,
    started_at TIMESTAMP DEFAULT NOW(),
    finished_at TIMESTAMP,
    duration_ms INTEGER
);

CREATE INDEX idx_executions_workflow_id ON executions(workflow_id);
CREATE INDEX idx_executions_status ON executions(status);
```

### 2.3 Agent节点表 (agent_nodes)
```sql
CREATE TABLE agent_nodes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    workflow_id UUID REFERENCES workflows(id),
    node_id VARCHAR(50) NOT NULL,  -- 前端节点ID
    node_type VARCHAR(50) NOT NULL,  -- llm, code, http, condition
    config JSONB NOT NULL,  -- 节点配置
    position_x FLOAT,
    position_y FLOAT
);
```

### 2.4 执行日志表 (execution_logs)
```sql
CREATE TABLE execution_logs (
    id BIGSERIAL PRIMARY KEY,
    execution_id UUID REFERENCES executions(id),
    node_id VARCHAR(50),
    log_level VARCHAR(10),  -- INFO, WARN, ERROR
    message TEXT,
    timestamp TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_logs_execution_id ON execution_logs(execution_id);
```

## 五、Agent执行引擎设计

### 5.1 执行流程
```
用户触发执行
    ↓
解析YAML工作流定义
    ↓
构建执行DAG（有向无环图）
    ↓
拓扑排序确定执行顺序
    ↓
依次执行各节点：
  - LLM节点 → 调用OpenClaw Agent
  - Code节点 → 沙箱执行Python/JS代码
  - HTTP节点 → 发起HTTP请求
  - Condition节点 → 条件判断，选择分支
    ↓
收集执行结果，返回给用户
```

### 5.2 节点执行器接口
```python
class NodeExecutor(ABC):
    @abstractmethod
    async def execute(self, config: dict, inputs: dict) -> dict:
        pass

class LLMNodeExecutor(NodeExecutor):
    async def execute(self, config, inputs):
        # 调用OpenClaw Agent
        agent = OpenClawAgent(model=config['model'])
        response = await agent.run(prompt=config['prompt'].format(**inputs))
        return {"response": response}

class CodeNodeExecutor(NodeExecutor):
    async def execute(self, config, inputs):
        # 沙箱执行代码
        result = await sandbox_exec(config['code'], inputs)
        return {"result": result}
```

## 七、技术风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| OpenClaw Agent框架扩展复杂 | 高 | 先基于现有API封装，逐步深入 |
| ReactFlow画布性能（>100节点） | 中 | 使用虚拟化渲染，限制单次显示节点数 |
| 代码执行沙箱安全性 | 高 | 使用Docker容器隔离，限制资源 |
| 行业模板实用性不足 | 中 | 与3-5家潜在客户沟通需求 |
